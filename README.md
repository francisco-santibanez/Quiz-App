# 📚 Grunderna: Git, GitHub och HTML

En kort och lättförståelig genomgång av verktygen och teknikerna som utgör grunden för webbutveckling och interaktionsdesign.

---

## 1. Git och GitHub – Tidsmaskinen och samarbetshubben

Att lära sig Git och GitHub kan kännas abstrakt i början, men när man väl knäcker koden blir det oumbärligt.

* **Git (Versionshantering):** Tänk dig Git som en **avancerad tidsmaskin för dina filer**. Istället för att spara ner otaliga kopior som `arbete_slut_v1.html`, `arbete_slut_v2_fardig.html` och riskera att radera något viktigt, sparar Git små "snapshots" (så kallade *commits*) av exakt vad du ändrat. Om koden kraschar kan du när som helst backa tillbaka till en tidigare fungerande punkt.

* **GitHub (Molntjänsten):** GitHub är plattformen på nätet (molnet) där du lagrar dina Git-repon. Det är här din kod blir synlig för andra, där du bygger din digitala portfölj inför arbetslivet, och där flera utvecklare kan samarbeta i samma projekt utan att skriva över varandras ändringar.

---

## 2. HTML (HyperText Markup Language) – Webbens skelett

HTML är inte ett programmeringsspråk med logik och beräkningar, utan ett **markeringsspråk (markup language)**.

* **Vad den gör:** HTML bygger upp **strukturen och innehållet** på en webbsida. Det är som skelettet i en kropp.
  
* **Hur den fungerar:** Du använder så kallade taggar för att berätta för webbläsaren vad olika delar av texten eller innehållet är för något:
  * En huvudrubrik (`<h1>`)
  * Ett stycke löpande text (`<p>`)
  * En bild (`<img>`)
  * En klickbar länk (`<a>`)
  
* **Helheten:** HTML ger innehållet sin struktur. Vill du lägga till färg, snygga typsnitt och layout använder du **CSS** (som blir webbsidans "kläder"), och vill du ha dynamisk funktionalitet (som interaktiva element) kopplar du på **JavaScript**.
